# Roadmap

## Now (active development)

- Bug fixes and accessibility improvements (keyboard navigation, aria-labels)
- Code quality: remove dead code, extract shared utilities
- Keep documentation up to date

## Next

- User accounts & sign-in (replace guest mode)
- Push notifications when a voted slot is booked
- Improve group voting UX: winner highlight, expiry countdown

## Later

- Native mobile apps (React Native or PWA enhancements)
- Additional regions and language support
- Alternative court-booking platforms beyond Playtomic
