# Product Strategy

## Vision

Make finding and coordinating Padel games effortless — from discovering available court slots to agreeing on a time that works for the whole group.

## Target Users

- Recreational Padel players who play regularly and want to minimise the friction of booking.
- Groups of players who need to coordinate across multiple schedules.

## Channels

| Channel | Status | Notes |
|---|---|---|
| Web app | Live | React + FastAPI, hosted on Railway |
| WhatsApp bot | Live | neonize, same AI agent as web |

## Differentiators

- **Group Voting** — First-class support for multi-player schedule coordination; no external tools needed.
- **AI assistant** — Natural language queries via Chat Mode; agent remembers preferences.
- **Dual mode** — Find Mode for power users who want speed; Chat Mode for discovery and edge cases.
